# Detektiv-Figur – final (Hood-Prinzip, eigener Charakter)

Was beim Ninja funktioniert:
- **Mensch**, normale Proportionen (nicht Chibi, nicht süß)
- Hochwertige **3D-Emoji-Optik** (wie Apple-Emoji, nur detaillierter)
- Gesicht **teilweise verdeckt** → anonym, aber Augen sichtbar → Emotionen möglich
- **Ein typisches Requisit** (Schwert) → bei uns: Lupe
- Brustbild, **weißer Hintergrund**, leicht schräg

Was bei den letzten Bildern falsch war: zu süß, Chibi, Spielzeug-Look.

## Tipps für Flow
- Format auf **1:1** stellen (nicht 16:9) → besser für Profilbild + Freistellen
- Pro Prompt 4 Bilder
- Wenn fast gut: Bild öffnen → „Was möchten Sie ändern?“ → z. B. `make the eyes more serious` oder `less cute, more mysterious`
